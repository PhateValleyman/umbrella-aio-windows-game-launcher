# Licensing and Attribution

## Main project
The Winlator root repository contains the GNU Lesser General Public License, version 2.1 (LGPL-2.1). Preserve the complete license text and all copyright notices.

## Android application
The upstream Android application repository is also distributed under LGPL-2.1. Keep its license and notices in the application fork.

## Third-party components
Winlator integrates or distributes third-party components, including Wine, Box86/Box64, Mesa (Turnip/Zink/VirGL), DXVK, VKD3D, CNC DDraw, and other native/runtime components. Each component may have its own license and attribution requirements. This list is not a substitute for a complete component inventory.

## Distribution requirements
Before publishing an APK or component bundle:
- Inventory every included component and exact version.
- Preserve upstream notices and license files.
- Include required corresponding source and build scripts where the applicable license requires them.
- Document modifications and their dates.
- Do not imply that Umbrella is endorsed by the upstream Winlator developers.
- Do not remove or replace upstream attribution with Umbrella branding.
